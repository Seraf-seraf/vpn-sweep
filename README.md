# vpn-sweep

CLI на Go для поиска работоспособного сочетания клиентских параметров по импортированным VPN/proxy-конфигурациям. Серверы и реквизиты задаются входными конфигурациями: инструмент не сканирует неизвестные серверы и не подбирает учётные данные.

Проверки выполняются через локальный SOCKS внешнего Xray без direct fallback. Первый полный успех по policy серии останавливает поиск, сохраняет результат локально и завершает тестовый туннель. Результат подтверждает только проверенные ресурсы и возможности в текущих условиях сети; универсальный обход и постоянная работоспособность не обещаются.

## Возможности и статус

- Импорт поддерживаемых JSON-конфигураций, массивов и ссылок отдельных конфигураций из локального файла или stdin. CLI не загружает URL подписок и не принимает base64-обёртку всего входа; список отдельных URI, в том числе полученный из подписки, можно передать локально. Неизвестные поля, цепочки и сочетания отклоняются; произвольный Happ JSON не гарантированно совместим.
- Ленивый детерминированный поиск взаимодействий параметров, дедупликация и раздельные идентификаторы серии, кандидата и попытки. Адреса, порты, авторизация и серверный transport/security-контракт сохраняются.
- Управляемые бюджеты времени, попыток, полезной нагрузки и журнала; сохранение прогресса и resume.
- Содержательные HTTPS-проверки с TLS verification, проверкой ответа и повторением после перезапуска ядра. Ping, открытый порт, запуск Xray и произвольный HTTP200 не считаются полным успехом.

Программа использует внешний Xray с commit `ac5d8a8` (полный SHA: `ac5d8a83ba798c390cd89f235c3d4c35c77c1586`). Runner проверяет commit в выводе версии, фиксирует SHA-256 бинарника и проверяет конфигурацию перед запуском. Одного номера версии Xray недостаточно.

Конфигурации из Happ проходят тот же импорт и проверяются через Xray; отдельного режима нет. Применение настроек интерфейса Happ не подтверждено. Обычный CLI SOCKS не перенаправляет весь Android-трафик; системный VPN/TUN, MTU и per-app VPN не проверяются. QUIC/HTTP3 unsupported; TCP-успех не засчитывается как QUIC. Android ARM64 cross-build выполнен, приёмка на устройстве остаётся unverified.

## Сборка и первый запуск без сети

Требуются Git, Go **1.24+** и Make. Проверенный компилятор — Go 1.27.2. Сторонних Go modules нет; внешнее ядро Xray в сборку не входит.

```sh
git clone https://github.com/Seraf-seraf/vpn-sweep.git
cd vpn-sweep
make build
./build/vpn-sweep version
./build/vpn-sweep help
./build/vpn-sweep inspect --input - --format json < examples/input.json
./build/vpn-sweep space
```

Эти команды не запускают VPN и не проверяют интернет. `examples/input.json` — синтетическая конфигурация с адресами `.invalid`. CLI использует команду `help`, а не флаг `--help`.

Для целевого Android ARM64 artifact:

```sh
make android
```

Результат — `build/vpn-sweep-android-arm64`. Для Android используйте ARM64 artifact, а не Linux-бинарник. Установка Termux, приватный импорт и последовательность run/resume описаны в [инструкции Termux](docs/google-youtube-termux.md).

## Встроенные проверки

Новый поиск использует `google-youtube-web-noise-v1`: HTML-страницы Google и YouTube
обязательны в обоих раундах с перезапуском Xray между ними. Для кандидата с `noise=true`
в обоих раундах также обязательна UDP/DNS-проверка через SOCKS; при `noise=false` она
не выполняется. Скачивание файлов и видео не проверяются. Команда `policy` проверяет
встроенные правила offline. Preset имеет статус live-unverified.
Старые серии с проверкой YouTube-видео доступны для просмотра и экспорта подтверждённых
результатов; для нового поиска без видео нужна новая серия.

## Приватные данные, запуск и resume

Настоящие VPN-конфиги, state и результаты храните **вне checkout** и общего Android `/sdcard`: файлы с правами `0600`, приватные каталоги `0700`. Не помещайте реквизиты в argv, историю команд или issues. `.gitignore` не удаляет уже отслеживаемые секреты; secret scan — дополнительная эвристика, не гарантия.

Перед запуском нужны совместимый input и внешний Xray. Наличие другого VPN автоматически не определяется и не подтверждается; в отчёте среда отмечается как unverified. Программа не меняет системную сеть.

Остановка — Ctrl-C. Resume использует сохранённые входы и условия серии; изменённый core требует новой серии; изменение сети автоматически не определяется. Operational budgets задаются на каждый запуск. Полное описание flags, exit codes и форматов: [usage](docs/usage.md).

При успехе приватный каталог результата содержит:

- `working.json` — готовый конфиг с необходимыми реквизитами;
- `verification.json` — policy и условия проверки;
- `report.json` — результаты, scope и ограничения;
- `COMPLETE.json` — завершающий маркер целостности экспорта.

`status` показывает состояние серии, `report` — журнал попыток. `capability_blocked` сохраняет кандидата для retry; это не доказательство неисправности сервера. Исчерпание бюджета означает pause. Исчерпание пространства означает «рабочее соединение не найдено в исследованном пространстве».

## Локальные проверки

Для полного набора проверок нужны Go и Python 3. Интеграционные проверки используют loopback, не реальные YouTube/VPN.

В Linux-среде разработки:

```sh
umask 077
make check
make build android
```

`make check` выполняет проверку форматирования, scanner tests, secret scan, vet, race suite и обе сборки. Тестовые fixtures требуют `umask 077`. Если среда помечает `/tmp` как Git checkout, для тестов нужен доступный приватный temp root вне checkout, например `TMPDIR=/var/tmp` на Linux. Это не путь для Termux.
