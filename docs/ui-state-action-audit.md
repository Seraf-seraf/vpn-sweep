Scope: source-level review of the existing Android UI and its controllers. Confirmed means established from code or the stated focused fake checks; it does not mean exercised on a device. The reported phone interruption has no established root cause. No subscription content is included here.

| Surface | Source of state and action | Confirmed behavior and boundary | Not exercised |

| Subscription form | `SubscriptionDialog.kt`, `SubscriptionController` | HTTPS authority is checked before submit; rejection is visible and valid input can be retried. | Server selection | `SubscriptionController.select`, `AppComposition.commitSelection` | Committed IDs change only after source mutation succeeds. | Search and cancellation | `SearchController`, `ProductionSearchPort`, `SearchSessionProducer` | Start uses receipt/revision and owner gates; rejected or unknown outcomes do not imply a clean result. ## Visible controls and outcomes

The following rows describe source-confirmed behavior; UI interaction, accessibility services and device effects are not exercised by these observations. Main composition and callbacks are in `MainActivity.kt:74–171`; control presentation is in `ui/VpnSweepScreen.kt`.

| Control or text | Predicate, handler and state consequence |
| --- | --- |
| Power | Uses current VPN busy/result readiness. When busy the action requests `SweepVpnService.STOP`; otherwise it starts notification permission and the guarded VPN preparation path. VPN consent denial and absent result do not start VPN; the notification permission callback ignores its Boolean and proceeds to VPN preparation. |
| Add subscription | Enabled by `sourceEnabled`: not VPN-busy, not searching and not loading. Opens the subscription dialog; accepting a request closes the dialog, while a refused request stays visible with a safe unavailable status. |
| Servers | Same source guard; opens a selector over installed records. Its summary is the count of records and committed selected IDs; it is independent of VPN result readiness. |
| Search / cancel | Enabled by `graph.searchEnabled()` or a running search. A running action requests cancellation; otherwise it calls `startSearch`. Rejected, busy, unknown and interrupted outcomes are represented as safe events, not success. |
| Subscription input / submit / dismiss | `SubscriptionDialog.kt:81–149` validates non-opaque HTTPS with host, no userinfo or fragment and an allowed port. Empty/invalid input disables submit. Failed submission is visible; editing clears the local failure and valid input permits retry. Dismiss closes the dialog. Loading and controller failures are observable through existing state/journal; dismiss is not a claim that network cleanup completed. |
| Server filter / rows / select all | `ui/ServerSelectionDialog.kt:117–224` filters display fields, enables select-all only for visible supported IDs, and changes only local draft selection until OK. Unsupported rows cannot be selected. Empty states distinguish no loaded servers from no match. |
| Selection Cancel / OK / refresh | Cancel dismisses the draft. OK requires `canConfirm` and a nonempty selection and calls `graph.select`; only successful commit closes the dialog and emits saved. Failure leaves it open, shows “Не удалось сохранить выбор серверов”, and refreshes availability. “Проверить доступность снова” is shown when confirmation is unavailable; it does not start search. |
| Journal / parameters tabs | Selectable tabs change the active pane, each retaining its own scroll state. The shared height depends on viewport rather than event count. The source has no separate settings screen in this path. |
| Parameter groups | Fragment, Mux, TLS fingerprint and UDP noise rows toggle expansion and expose expanded/collapsed state. The panel says “Применённые параметры пока недоступны” when no applied values exist. Opening a group does not apply a setting. |
| Search status | `MainActivity.searchStatus` contains phase-to-text mappings but has no caller. `searchMessage` is passed as empty and `operationMessage` is not forwarded by the wrapper. The displayed home status is `VpnStatus.message`; Search state is visible through its button and journal. No status itself grants admission. |
| Foreground notification | `SweepVpnService.notification` uses title “VPN Sweep”, text “Подключение и состояние — в приложении”, opens MainActivity on tap and has “Отключить” action dispatching STOP. OS presentation and permission behavior were not exercised. |
| Accessibility | Tabs use selectable role; parameter groups use button role and expanded/collapsed state; selection checkboxes expose checked state and disabled rows. These are static source observations, not an accessibility-service test. |

`searchui/ScreenInformation.kt:45–109` is the authoritative event mapping. Subscription events cover loading, processed, failed, busy and cancelled; selection events cover saved/failed; search events cover starting, busy, rejection, unknown, interrupted, cancel requested, pause, cancelled, complete and failure. Fixed codes distinguish observed network policy unavailability and the four known worker OPEN failure categories. Events do not contain a subscription address, credential, profile or exception text. Typed reason observation is independent of ownership cleanup and must not be read as permission to retry.

### Exact labels and presentation states

- Power accessibility actions by phase: “Подключить VPN”, “Отменить подключение VPN”, “Отключить VPN”, “Отключение VPN”. The control is enabled only when not importing, not STOPPING, and there is a selected usable result or CONNECTING/RUNNING. Search button says “Подобрать настройки” or “Отменить подбор”.
- Subscription helper states: Empty “Ссылка нужна для загрузки серверов”; Input “Список серверов загрузится после «Ок»”; Loading “Загрузка серверов...”; InvalidUrl “Введите корректную ссылку”; NetworkError “Не удалось загрузить подписку” / “Проверьте соединение и повторите”; MalformedData “Не удалось прочитать подписку” / “Проверьте ссылку и формат данных”; Unavailable “Загрузка подписок пока недоступна”.
